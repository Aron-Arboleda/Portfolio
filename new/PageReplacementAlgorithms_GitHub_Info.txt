DESCRIPTION
--------------------------------------------------------------------------------
A desktop application built for a Finals Case Study in Operating Systems. It
visualizes the behavior of three Page Replacement Algorithms: FIFO (First-In-
First-Out), Optimal (OPT), and LRU (Least Recently Used).

One-liner (from GitHub):
  "A Desktop application that serves as a visualizer of the 3 main page
   replacement algorithms (FIFO, OPT, and LRU)."
