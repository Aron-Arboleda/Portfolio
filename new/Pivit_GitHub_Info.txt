DESCRIPTION
--------------------------------------------------------------------------------
A Python CLI program that gamifies productivity by letting users create to-do
lists as daily quests, add personal achievements to earn coins, level up their
character profile, and purchase items at a shop to enhance motivation and
engagement in staying productive.

One-liner (from GitHub):
  "CLI program, gamified todo and adding achievements (with coins, experience
   points, and game profile)"

--------------------------------------------------------------------------------
FEATURES
--------------------------------------------------------------------------------
- To-do lists framed as quests
- Gamified achievements system
- Users can level up using EXP (experience) points and upgrade their character
- Earning coins and EXP by completing quests and adding personal achievements
- In-game shop where users can buy different levels of items using coins

INSTRUCTIONS
--------------------------------------------------------------------------------
How to Run:
  - Pull the repository locally (VS Code recommended)
  - Install all necessary extensions/programs to run Python files in VS Code
  - Use the "Run Python File" button in VS Code to launch the program

How to Use:
  - Creating an account is required (username + password)
  - Type /commands at any level to see available commands
  - Actions available: add/update quests, add achievements, buy items, etc.

--------------------------------------------------------------------------------
PROGRAM LIMITATIONS
--------------------------------------------------------------------------------
- CLI only — no graphical user interface (noted as the developer's first project)
- User data is stored in plain text files (ProductivityAccounts.txt &
  ProductivityUsersData.txt), not in a secured database
