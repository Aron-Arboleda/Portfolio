DESCRIPTION
--------------------------------------------------------------------------------
It is a database made with the MS Access technology and served as our case study
for CC6 (Information Management). This is includes implementation of a RDBMS with
the application of entity relationships, constructiong ERDs, data lifecycle 
management, and how to make a functional database system using MS Access

One-liner (from GitHub):
  "A Microsoft Access database for the ASEAN Library data, it contains books,
  reading materials, pictures, and paintings that helps conserve the culture of
  ASEAN countries"

--------------------------------------------------------------------------------
FEATURES
--------------------------------------------------------------------------------
- Data storage for different kindly of ASEAN literatures.
- User interfaces to navigate and manage all the data.
- Robust and error-free inputting using MS Access code blocks.
- Filtering, sorting, all present in the system.
