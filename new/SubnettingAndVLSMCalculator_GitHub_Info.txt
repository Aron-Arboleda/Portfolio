DESCRIPTION
--------------------------------------------------------------------------------
A web application dedicated to helping networking professionals quickly and
accurately divide and subnet networks. The platform caters to individuals of
all skill levels, offering intuitive tools and resources for efficient network
segmentation. With a seamless interface, it simplifies the complexities of
network subdivision, saving time and enhancing productivity.

One-liner (from GitHub):
  "Web app, subnetting and VLSM Calculator for networking practitioners"

--------------------------------------------------------------------------------
FEATURES
--------------------------------------------------------------------------------
- Calculates subnets for a given IP address and CIDR
- Calculates VLSM for a given IP address and list of required hosts
- User-friendly interface
- Responsive design

--------------------------------------------------------------------------------
FEATURES STILL IN DEVELOPMENT
--------------------------------------------------------------------------------
- Practice questions functionality for subnetting and VLSM
- Subnetting IPv6 networks
